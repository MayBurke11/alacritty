# Alacritty — Feature Ideas

> Discussed 2026-07-10

## CLI Flags

### `--create-systemd-unit`
Создаёт systemd user unit для IPC демона. Чтобы alacritty стартовал как фоновая служба с сокетом.

```bash
alacritty --create-systemd-unit
# Создаёт ~/.config/systemd/user/alacritty-ipc.service
# systemctl --user enable --now alacritty-ipc
```

### `--create-config`
Генерирует полный конфиг-файл со всеми секциями (tabs, menu, pane, session).

```bash
alacritty --create-config > ~/.config/alacritty/alacritty.toml
```

### `--create-links`
Создаёт `.desktop` файлы / ярлыки в меню приложений.

```bash
alacritty --create-links
# Создаёт ~/.local/share/applications/alacritty.desktop
```

## Pane/Tab Focus Cycling

Когда >1 панелей в табе и мы смещаем фокус (Alt+→):

- Дошли до крайнего правого панели → следующее нажатие Alt+→ переходит на ПРАВЫЙ таб и его КРАЙНИЙ ЛЕВЫЙ панель
- Аналогично в обратную сторону: Alt+← с крайнего левого панели → левый таб, крайний правый панель
- Фокус ходит по кругу через все табы и панели

## Alt+F4

Почему не закрывается через Alt+F4? Нормальное ли это поведение?
Сейчас: `decorations = "None"` — системные хоткеи не работают.
Нужно: добавить `Action::Quit` на `Alt+F4` в дефолтных биндингах (или оставить как есть и задокументировать).

## Pane:Hide

Возможность скрыть панель (теряет ширину/высоту, игнорируется при рендеринге).
Использование: сайдбары, временно скрытые панели.

```
Ctrl+G, p, h  →  PANE → HIDE
```

Реализация: флаг `hidden: bool` на `PaneState`. `PaneNode` с `Leaf` получает `hidden` флаг. При `leaf_rects()` скрытые листья получают `width=0` или `height=0`.

## Hints для Взаимодействия с Меню

Подсветка пунктов меню (hints) как в vimium/tridactyl:
- Каждый пункт меню получает метку (as, df, jk...)
- Нажатие метки = выбор пункта
- Альтернатива letter-key навигации

## Всплывающие Окна (Popups)

Временные окна поверх терминала:
- Выбор файла
- Выбор сессии
- Command palette
- Подтверждение действий

## Кастомизация Окон

Не только UI:
- К какому X-серверу подключаться
- На каком мониторе открываться
- Wayland/X11 выбор

## Remote Editing

Подключение к удалённому серверу с прозрачным редактированием:
- Терминал подключается к remote SSH
- Файлы открываются локальным редактором через scp/sshfs
- Пользователь не замечает разницы между локальным и удалённым файлом
