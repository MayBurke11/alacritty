# Хоткеи Zellij: модальная система с разблокировкой

## Как это работает с точки зрения пользователя

Zellij построен на **модальной системе** с двумя ключевыми состояниями: **Locked** (заблокирован) и **Normal** (разблокирован). Всё взаимодействие — это трёхшаговая цепочка:

1. **Снять блокировку** — переключить Zellij из locked в normal mode
2. **Выбрать объект взаимодействия** — сказать Zellij, с чем вы хотите работать (панели, вкладки, сессия, скролл и т.д.)
3. **Выбрать действие** — сказать, что именно сделать с этим объектом

---

## Принцип: нижняя панель как подсказка и как меню

В Zellij есть **status bar** — нижняя строка. Она работает одновременно как:

- **Подсказка** — показывает, в каком вы сейчас режиме и какие клавиши доступны
- **Меню** — каждая буква на этой панели — это активная кнопка

Когда вы снимаете блокировку (`Ctrl + g`), Zellij переходит в **Normal mode**. Внизу вы видите строку с режимами:

```
PANE | TAB | RESIZE | MOVE | SCROLL | SESSION
```

Каждое слово — это **объект взаимодействия**, и его первая буква — это **клавиша-активатор**:

- **P** → `Ctrl + p` → режим **Pane** (работа с панелями)
- **T** → `Ctrl + t` → режим **Tab** (работа с вкладками)
- **R** → `Ctrl + n` → режим **Resize** (изменение размеров)
- **M** → `Ctrl + h` → режим **Move** (перемещение панелей)
- **S** → `Ctrl + s` → режим **Scroll** (прокрутка)
- **O** → `Ctrl + o` → режим **Session** (управление сессией)

После выбора режима нижняя панель меняется — показывает **действия**, доступные для этого объекта. Каждое действие тоже активируется одной клавишей.

## Pane (панели) — `Ctrl + g` → `Ctrl + p`

После входа в режим Pane внизу появляется:

```
h/j/k/l — навигация | n — новая | d — вниз | r — вправо | x — закрыть | f — на весь экран | c — переименовать | ...
```

**Пример: создать новую панель справа**

```
Ctrl + g   →   Ctrl + p   →   r
(разблокировать)  (выбрать Pane)  (New → Right)
```

Полная цепочка: `Ctrl + g`, `Ctrl + p`, `r`

**Другие действия в режиме Pane:**

| Клавиша | Действие | Мнемоника |
|---|---|---|
| `n` | Новая панель (авто-раскладка) | **N**ew |
| `d` | Новая панель **D**own (снизу) | **D**own |
| `r` | Новая панель **R**ight (справа) | **R**ight |
| `s` | Новая панель **s**tacked (стопкой) | **S**tacked |
| `x` | Закрыть панель (kill) | **X** (close) |
| `f` | На весь экран (fullscreen) | **F**ullscreen |
| `c` | Переименовать панель (rename) | **C** — `Ctrl + c` для выхода |
| `z` | Убрать/показать рамки панелей | **Z** (toggle frames) |
| `w` | Показать/скрыть floating-панели | **W**indows |
| `e` | Встроить/открепить панель | **E**mbed |
| `i` | Закрепить панель (pin) | **I** (pin) |
| `p` | Переключить фокус между панелями | **P** (switch focus) |
| `h/j/k/l` | Навигация (влево/вниз/вверх/вправо) | Vim-клавиши |

## Tab (вкладки) — `Ctrl + g` → `Ctrl + t`

После входа в режим Tab нижняя панель показывает:

```
n — новая | x — закрыть | r — переименовать | h/l — навигация | s — sync mode | b — break pane | 1-9 — перейти к вкладке
```

**Пример: создать новую вкладку**

```
Ctrl + g   →   Ctrl + t   →   n
(снять блок)   (выбрать Tab)   (New)
```

**Пример: переименовать вкладку**

```
Ctrl + g   →   Ctrl + t   →   r
(снять блок)   (выбрать Tab)   (Rename)
```

После нажатия `r` Zellij переходит в режим **RenameTab** — вы вводите новое имя и нажимаете Enter. `Esc` отменяет переименование.

**Пример: переключиться на вкладку 3**

```
Ctrl + g   →   Ctrl + t   →   3
```

**Все действия в режиме Tab:**

| Клавиша | Действие | Мнемоника |
|---|---|---|
| `n` | Создать новую вкладку | **N**ew |
| `x` | Закрыть текущую вкладку | **X** (close) |
| `r` | Переименовать вкладку | **R**ename |
| `h` / `k` / `Left` / `Up` | Предыдущая вкладка | Vim-навигация |
| `l` / `j` / `Right` / `Down` | Следующая вкладка | Vim-навигация |
| `s` | Sync mode (ввод во все панели) | **S**ync |
| `b` | Break pane (открепить в новую вкладку) | **B**reak |
| `]` | Break pane вправо | — |
| `[` | Break pane влево | — |
| `1`–`9` | Перейти к вкладке 1–9 | Номер вкладки |
| `Tab` | Переключиться на предыдущую вкладку | **Tab** |

## Session (сессия) — `Ctrl + g` → `Ctrl + o`

После входа в режим Session нижняя панель показывает:

```
d — detach | w — session manager | c — configuration | p — plugin manager | a — about | s — share | l — layout manager
```

**Пример: сохранить сессию**

```
Ctrl + g   →   Ctrl + o   →   Ctrl + s
(снять блок)   (выбрать Session)   (Save)
```

`Ctrl + s` в режиме Session — это `SaveSession` (сохранить состояние сессии на диск немедленно). Имя файла берётся из имени сессии, подтверждение не требуется.

**Пример: открепиться от сессии (detach)**

```
Ctrl + g   →   Ctrl + o   →   d
(снять блок)   (выбрать Session)   (Detach)
```

**Пример: открыть session manager (плагин)**

```
Ctrl + g   →   Ctrl + o   →   w
(снять блок)   (выбрать Session)   (Window manager)
```

**Все действия в режиме Session:**

| Клавиша | Действие | Мнемоника |
|---|---|---|
| `d` | Открепиться от сессии (detach) | **D**etach |
| `w` | Открыть session manager (плагин) | **W**indow manager |
| `c` | Открыть configuration (плагин) | **C**onfiguration |
| `p` | Открыть plugin manager (плагин) | **P**lugin manager |
| `a` | О программе (about) | **A**bout |
| `s` | Открыть share (расшарить сессию) | **S**hare |
| `l` | Открыть layout manager (плагин) | **L**ayout manager |
| `Ctrl + s` | Сохранить сессию на диск (save) | **S**ave |
| `Ctrl + c` | Выйти из режима Session | — |

## Как это выглядит в конфиге

Вот как эти режимы и переходы описаны в `config.kdl` (Zellij 0.44.3):

```kdl
keybinds {
    // Locked mode — все клавиши уходят в терминал
    locked {
        bind "Ctrl g" { SwitchToMode "Normal"; }
    }

    // Normal mode — выбор объекта взаимодействия
    shared_except "locked" {
        bind "Ctrl g" { SwitchToMode "Locked"; }  // заблокировать обратно
        bind "Ctrl p" { SwitchToMode "Pane"; }    // панели
        bind "Ctrl t" { SwitchToMode "Tab"; }      // вкладки
        bind "Ctrl n" { SwitchToMode "Resize"; }   // размеры
        bind "Ctrl h" { SwitchToMode "Move"; }     // перемещение
        bind "Ctrl s" { SwitchToMode "Scroll"; }   // прокрутка
        bind "Ctrl o" { SwitchToMode "Session"; }  // сессия
        bind "Ctrl b" { SwitchToMode "Tmux"; }     // tmux-совместимость
    }
}
```

Каждый режим — это отдельный блок `keybinds { <mode> { ... } }` в конфиге. Внутри — биндинги клавиш на действия. После выполнения действия обычно идёт `SwitchToMode "Normal"`, чтобы вернуться в normal mode, а оттуда — `Ctrl + g` возвращает в locked.

## Резюме: паттерн взаимодействия

```
1. Снять блокировку:     Ctrl + g
2. Выбрать объект:       Ctrl + <буква режима>   (p / t / o / n / h / s)
3. Выбрать действие:     <клавиша действия>      (n / r / x / d / ...)
```

Или коротко:

```
Ctrl + g  →  Ctrl + <объект>  →  <действие>
```

Нижняя панель (status bar) — это ваш навигатор. Она всегда показывает, где вы находитесь и что можно нажать дальше.
